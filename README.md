# Codex Desktop

## Latest: 1.0.7

- Removed unreliable ChatGPT/Codex switch actions.
- Kept the plugin focused on the working Open Codex action.
- Packages build as versioned standalone `.lplug4` files.

Codex Desktop is a Logi Options+ plugin for controlling ChatGPT/Codex Desktop on Windows from an MX Creative Console Keypad.

## Actions

| Action | Description |
| --- | --- |
| Open Codex | Finds `codex.exe` and runs `codex app`. |

## Package

- Display name: Codex Desktop
- Logi plugin id: CodexDesktop
- Version: 1.0.7
- Runtime: Node.js plugin through Logi Plugin Service
- Target device: MX Creative Console Keypad through Logi Options+
