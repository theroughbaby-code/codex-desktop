# Codex Desktop

## Latest: 1.0.5

- Packages now build as versioned standalone `.lplug4` files.
- Build verification blocks `pluginapi.dll`, local project paths, and repo links from package artifacts.

Codex Desktop is a Logi Options+ plugin for controlling ChatGPT/Codex Desktop on Windows from an MX Creative Console Keypad.

## Actions

| Action | Description |
| --- | --- |
| Open Codex | Finds `codex.exe` and runs `codex app`. |
| ChatGPT | Opens/focuses the desktop app and switches to ChatGPT mode. |
| Codex | Opens/focuses the desktop app and switches to Codex mode. |

## Package

- Display name: Codex Desktop
- Logi plugin id: CodexDesktop
- Version: 1.0.5
- Runtime: Node.js plugin through Logi Plugin Service
- Target device: MX Creative Console Keypad through Logi Options+
